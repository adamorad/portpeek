portpeek-mcp

No app. Just the server.

A headless CLI that runs the MCP server in the background. No GUI, no menu bar. Same 4 tools, same config — zero overhead.

brew install adamorad/tap/portpeek-mcp
curl -Lo portpeek-mcp.zip https://github.com/adamorad/portpeek/releases/latest/download/portpeek-mcp-macos-arm64.zip && unzip portpeek-mcp.zip && mv portpeek-mcp /usr/local/bin/
git clone https://github.com/adamorad/portpeek && cd portpeek/mcp-server && swift build -c release

Add to your agent config

{"mcpServers":{"portpeek":{"url":"http://localhost:27182"}}}
